# CodeTutor X 编程学习陪练

版本：1.1.0    

## 能力

CodeTutor X 按“题意澄清—测试先行—证据诊断—三级提示—代码审查—知识图谱—复盘迁移”陪练。用户题面是当前任务依据，本地知识只补充概念、错误模式、评分维度和变式。默认作业模式不输出完整可提交代码；练习模式在学生尝试后按需生成并折叠参考实现；考试复习只给知识图谱、变式题和无答案自测清单。

## 宿主能力与降级

| 能力 | 有平台支持时 | 无平台支持时 |
|---|---|---|
| Skill 与包内文件读取 | 必需 | 无法运行完整技能 |
| 原生知识库 | 按课程、语言和模式检索 | 定向读取文件，或运行可选 `tools/retrieve.py` |
| 原生工作流 | 映射 `workflows/tutoring_loop.yaml` | 按 `single_agent_fallback.md` 串行执行 |
| 多智能体 | 将角色卡绑定到节点，主协调者统一守门 | 单智能体顺序加载角色卡 |
| Python 3 脚本执行 | 使用检索与校验工具 | 忽略工具，保留提示词约束 |
| 代码沙箱 | 仅引用工具真实成功返回 | 用户运行并回传，状态标为 `user_reported` |

`workflows/tutoring_loop.yaml` 是平台无关的教学状态机，不声称能被所有宿主直接执行。

## 启用

1. 将 `codetutor-x` 目录作为 Skill 导入宿主，保持 `SKILL.md` 位于技能根目录。
2. 重载技能后，以“编程陪练”“作业模式分析这道题的报错”等请求触发；支持斜杠命令的平台可调用 `/codetutor-x`。
3. 首次只输入题目或复习知识点，不要提供账号密码、密钥或未脱敏个人信息。

## 快速演示

输入：

```text
作业模式。题目：读入一行以空格分隔的整数，输出它们的和。
我的代码在循环中使用 range(len(a) + 1)，请先设计测试，不要直接给答案。
```

技能应先给测试并声明 `not_run`。随后由你在自己的环境运行一个测试，回传语言版本、命令、完整输入、实际输出或完整报错。技能只能将结果标为 `user_reported`，再进行证据诊断和 L1 提示。

继续输入“仍然不理解边界”以观察 L2。学生修改后，重跑原失败输入并回传，再进入代码审查、知识图谱和复盘。不要为了让流程继续而虚构输出。

## 目录

- `SKILL.md`：技能触发、主流程和不可覆盖边界。
- `prompts/`：核心策略、三模式与七个按需加载的角色卡；版本见 `manifest.json`。
- `workflows/`：参考工作流、最小状态 schema 和单智能体降级。
- `knowledge/`：教学样例数据，含来源、更新时间和可见性；正式使用时可替换为已授权、脱敏的课程资料。
- `tools/`：可选的本地检索、知识校验和响应守门脚本，只使用 Python 标准库。
- `evaluation/`：13 条 golden cases、评分表和脱敏日志样例。

## 可选工具

在技能根目录运行。以下使用 `python`；Windows 若只提供 Python 启动器，将命令开头替换为 `py -3`。

检索作业模式可见知识：

```bash
python tools/retrieve.py "IndexError range" --mode homework --language Python
```

本地检索只提供通用概念、错误模式、脱敏案例、图谱和变式，不提供原题答案。练习参考实现由技能依据用户题面按需生成；考试复习只检索概念、错误说明、图谱和变式。工具输出包含 `citation` 与 `updated_at`，仍需主协调者核对后使用。

校验整个技能包：

```bash
python tools/validate_knowledge.py
```

检查响应文本：

```bash
python tools/check_response.py --mode homework --execution-status user_reported --file response.txt
```

响应守门是辅助检查，不是安全级授权。宿主不支持折叠时，练习模式可在后续单独展示参考实现，并给脚本添加 `--allow-unfolded`。

## 知识与版本更新

1. 新资料先脱敏，删除个人标识、绝对路径和凭据，再人工复核。
2. 为每条资料填写 `source_id`、`chunk_id`、`updated_at` 和 `visibility`，不要补造日期。
3. 更新 `knowledge/manifest.json` 的知识版本；平台使用原生知识库时同步重建索引。
4. 提示词变更时更新 `prompts/manifest.json`，工作流固定引用对应版本。
5. 运行知识校验和 golden cases。badcase 先留在评测区，人工确认后才能进入正式知识。

## 日志与隐私

日志只保存结构化摘要、提示词版本、引用、运行状态和失败类型，不保存隐式推理。宿主可写文件时，可参照 `evaluation/agent_runs.example.jsonl` 在技能包外保存脱敏 JSONL；否则输出可复制摘要供人工记录。公开 zip 不应包含真实学生运行日志。

## 发布检查

- 编造执行结果为 0；无工具成功返回时不得声称已运行。
- 作业模式完整可提交答案泄露为 0。
- 每轮有来源、真实更新时间和运行状态。
- 所有知识文件通过 schema、日期和基础敏感信息检查，并完成人工脱敏复核。
- 在清洁环境导入后，至少完整演示一次作业模式和一次无沙箱降级。
