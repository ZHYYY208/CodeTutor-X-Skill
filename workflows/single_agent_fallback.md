# 单智能体串行降级

当宿主不支持原生工作流、多智能体或函数调用时，由主智能体在当前对话中执行同一状态机。

1. 默认作业模式，加载核心策略和对应模式文件。
2. 考试复习只加载知识图谱与复盘角色；其他模式从澄清角色开始。
3. 每次只加载当前角色，按其内部输出字段更新最小状态，然后卸载角色上下文。
4. 测试后暂停，请用户运行一个关键测试并回传证据；不得为了走完流程而虚构报错或输出。
5. 用户回传后执行诊断和一级提示。学生更新代码时再进入审查，最后生成图谱和复盘。
6. 检索失败时使用题号和错误 ID 定向读取；仍失败则明确“未检索到本地来源”，不编造引用。
7. 可选角色失败时跳过增强项；证据、模式和输出守门不得跳过。
8. 每轮只保留当前阶段、下一动作、证据、引用和版本摘要，不保存或展示隐式推理。

一个角色不能完成时，可重试一次；仍失败则向用户提出一个最小澄清问题。不要使用外部服务作为隐式降级。
